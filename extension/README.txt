MEILONG SCISSORS COUNTER v5.0.0

Polished Chrome/Edge Manifest V3 extension for the Sports In Focus event gallery.

FEATURES
- Individual and team clipped-photo detection.
- Optional automatic selection of matches.
- Clear current selections.
- Draggable and collapsible floating panel.
- Persistent panel position and preferences.
- Popup settings with enable/disable switch.
- Branded extension icons.

INSTALL
1. Open chrome://extensions/ (or edge://extensions/).
2. Enable Developer mode.
3. Choose Load unpacked.
4. Select the extension folder.
5. Visit a Sports In Focus event page matching the configured host pattern.
